PASSO A PASSO (uns 10 minutos)
------------------------------
1) GitHub: crie um repositório PRIVADO novo (ex.: painel-divida) e envie TODOS
   os arquivos desta pasta para a raiz dele (index.html, dados.mjs, acao.mjs,
   arquivo.mjs, auth.mjs, regras.mjs, sheets.mjs, blobs.mjs, netlify.toml,
   package.json). Pode arrastar pela tela do GitHub ("Add file > Upload files").

2) Netlify: "Add new site > Import from GitHub" e escolha esse repositório.
   Não precisa mexer em nada do build (o netlify.toml já faz tudo).

3) Em Site settings > Environment variables, crie duas variáveis:
   SHEET_ID = 1BLuHK5KZ555oNWG8yShZ6waBIJNkwW-30CDU5EOH0eY
   GOOGLE_SERVICE_ACCOUNT = (o mesmo JSON que você usa no painel do consórcio)

4) Em Deploys > Trigger deploy > Deploy site (pra pegar as variáveis).

5) Copie o endereço do site (algo.netlify.app) e cole na planilha, aba Config,
   célula B2 (site_url). Com isso a coluna "Link" da aba Acessos mostra o link
   de cada pessoa. É só mandar o link da Melissa pra ela.

COMO FUNCIONA O ACESSO
----------------------
Cada pessoa entra por um link: seusite.netlify.app/?k=CHAVE
As chaves estão na aba Acessos. Para tirar o acesso de alguém, troque "sim"
por "não" na coluna Ativo. Para trocar a chave, escreva outra.
